# \# CSC584 Individual Assignment 1 – Personal Profile Web Application

# 

# A simple web application that collects personal profile details in an HTML form,

# sends them to a Java Servlet using HTTP POST, and displays them on a styled JSP page.

# 

# \*\*Data flow:\*\* `index.html` (form) → `ProfileServlet` (POST) → `profile.jsp` (display)

# 

# \## Technologies Used

# \- HTML5 and CSS3

# \- Java Servlet and JavaServer Pages (JSP)

# \- Apache NetBeans (Java Web / Ant project)

# \- GlassFish Server 4.1.1

# 

# \## Requirements

# \- JDK 8 or newer (as supported by your GlassFish version)

# \- Apache NetBeans IDE

# \- GlassFish Server 4.1.1 (registered in NetBeans under Tools → Servers)

# 

# \## How to Run

# 1\. Clone or download this repository.

# 2\. In NetBeans, choose \*\*File → Open Project\*\* and select the project folder.

# 3\. Make sure GlassFish is selected: right-click the project → \*\*Properties → Run → Server\*\*.

# 4\. Right-click the project → \*\*Clean and Build\*\*, then \*\*Run\*\*.

# 5\. Open `http://localhost:8080/CSC584-Individual-Assignment-1/` in a browser.
